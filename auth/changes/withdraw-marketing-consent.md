### A withdrawal made in the marketing tool reaches the user's consent

`AuthService.WithdrawMarketingConsent` (`marketing_consent`) records that the user withdrew their marketing consent outside the project — they unsubscribed in the marketing tool — through the same statement and event as their own `SetMarketingConsent`: `User.marketing_consent` becomes false with its time, and `MarketingConsentChanged` announces it. It can only withdraw (a consent is the user's to give), and a withdrawal already on record is answered as it stands, so its time stays the user's. It names the user, so it is marked `(w17.contrib.plugin_internal_rpc)`: codegen refuses it on every surface, and only the domain's own code calls it — the business method a project binds to the marketing plugin's `consent_withdrawn` hook.
