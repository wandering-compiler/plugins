### A refusal a person reads is a translatable sentence

The refusals an organization or the backoffice reads carry a stable code and a sentence from the plugin's `msgids:`. A project's catalogs carry those sentences for translation. The refusals are: no organization named, a backoffice action from inside an organization, an envelope field that cannot be shown, a proposal already waiting, and an approval that raced another. The status message keeps the operator's text.
